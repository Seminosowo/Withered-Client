# Withered-Client
Utility modpack for Minecraft Anarchy servers based on Meteor Client and Meteor Addons with many other technical tools and GUI/HUD Improvements.
Meteor clients and other mods are additions on top of [Withered Utils](https://github.com/Seminosowo/Withered-Utils)

## Additions
- [Meteor Client](https://github.com/MeteorDevelopment/meteor-client)
- [Meteorist](https://github.com/Zgoly/Meteorist)
- [Meteor+](https://github.com/MeteorClientPlus/MeteorPlus)
- [Meteor Villager Roller](https://github.com/maxsupermanhd/meteor-villager-roller)
- [SeedCrackerX](https://github.com/19MisterX98/SeedcrackerX)
- [XaeroPlus](https://modrinth.com/mod/xaeroplus)
- [Litematica Printer](https://modrinth.com/mod/litematica-printer)

## Keybinds
| Mod | Feature | Keybind |
| Litematica Printer | Toggle Printing Mode | M+K |
| Meteor Client | Toggle HUD | Right Alt |
| Meteor Client | Freecam | V |
|Tweakaroo | GammaOverride | Y |

For other keybinds consult [Withered Utils Modrinth page](https://modrinth.com/modpack/withered-utils)
